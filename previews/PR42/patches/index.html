Patch items

Experimental

The patch surface may still change. Everything else in this documentation is contract; this page is a preview of the local-BVP layer.

A patch item is a set of cells with its own dof numbering — the unit of work for error estimators, localized-orthogonal-decomposition correctors, and other methods whose systems live on a neighbourhood rather than on one cell. The cell kernels are reused unchanged; only the scatter target is patch-local.

provider = PatchItems(sdh, cellsets)                 # one patch per cell set
dest = [zeros(patch_ndofs(provider, i), patch_ndofs(provider, i)) for i in eachindex(cellsets)]
assemble_patch_matrices!(dest, op, provider, states, p, ctx)

Rows and columns of dest[i] follow patch_dofs, the injection from patch-local into global numbering.

Solving the delivered local system is deliberately not part of the contract: the caller owns the solve. patch_free_dofs / patch_prescribed_dofs describe the interior/boundary split, and PatchItemStates is the item-lifetime storage a retained factorization belongs in — neither per-worker scratch nor operator-global frozen data.

Requests, terms and sinks

A patch request is a kind (PatchMatrixKind or PatchVectorKind) carrying a tuple of PatchTerms and a sink. Every term of one request is evaluated in a single pass over the patch's cells and accumulates into the same element buffer in tuple order — the accumulation order is part of the contract. A term's restriction is WholePatch or CellGroup, and its data payload selects either the element's ordinary cell kernel (nothing) or an assemble_patch_cell! term kernel.

The sink is the scatter mode: PatchLocalSink writes into a patch-local matrix or vector per item, PatchAssemblerSink goes through a Ferrite assembler per item, PatchGlobalVectorSink accumulates back into a global vector, and PatchTripletSink collects triplets for a rectangular assembly.

Patch sweeps are pure evaluation: condensed element unknowns are gathered but never written back, unlike the global sweeps. Sequential CPU only.

Patch API reference

FerriteOperators.AbstractPatchSink — Type

Supertype of the patch assembly sinks: where a patch's assembled matrix or vector goes. Matrix-vs-vector is the request dimension (PatchMatrixKind / PatchVectorKind); the sink is the scatter mode within it.

source
FerriteOperators.CellGroup — Type
CellGroup(id)

Term restriction: integrate only over the patch cells carrying the group tag id (see the groups argument of PatchItems). Group membership is tested inside the single pass over the patch's cells, so a restricted term accumulates in the same ascending cell order as an unrestricted one.

source
FerriteOperators.PatchAssemblerSink — Type
PatchAssemblerSink(dest)

Matrix sink through a Ferrite assembler per item (a cached column walk instead of a binary search per entry). dest[i] must be a sparse matrix over patch i's dofs whose pattern already holds every element entry; use PatchLocalSink when the pattern must grow.

source
FerriteOperators.PatchDofPartition — Type
PatchDofPartition(prescribed, free)

The view-derived dof partition of one patch, in PATCH-LOCAL numbering: prescribed are the dofs the caller's local BVP constrains (homogeneously — this layer carries no inhomogeneities), free is their sorted complement.

source
FerriteOperators.PatchGlobalVectorSink — Type
PatchGlobalVectorSink(dest)

Additive global-vector sink: patch i's assembled vector is accumulated into dest through the injection, dest[patch_dofs(provider, i)[l]] += v[l].

source
FerriteOperators.PatchItemStates — Type
PatchItemStates{S}(nitems)

Per-item state slots of element type S, indexed by item. Two uses, one mechanism — they differ only in the caller's invalidation policy:

  • item-lifetime state that must survive across sweeps (a retained factorization, a reduction snapshot),
  • the solve→scatter payload channel within one sweep (what a local solve hands to the phase that emits its result).

Freshness contract: FO never writes and never invalidates these slots. The caller stores with set_item_state!, tests with has_item_state, and drops stale content with invalidate_item_state! when whatever the slot was derived from changes. Slots are indexed by ITEM, so items processed by different workers touch disjoint slots — item lifetime is not worker lifetime, and a slot must never be handed to a worker-lifetime cache.

source
FerriteOperators.PatchItems — Type
PatchItems(sdh, cellsets; groups, prescribed_facets, field)

Work-item provider over patches: item i is the cell set cellsets[i] (cells of sdh) with its own contiguous patch-local dof numbering. The injection map back to global dofs is patch_dofs.

Keyword arguments:

  • groups: per patch, a group tag per cell (aligned with the sorted cell list of that patch), the index a CellGroup restriction selects on. Defaults to the cell ids themselves, i.e. CellGroup(cellid) restricts to a single cell. The natural tagging for a multiscale patch is the parent coarse cell.
  • prescribed_facets: per patch, an iterable of FacetIndex on the patch's cells that the local BVP prescribes. FO does NOT classify the boundary — which facets are cut boundary is caller geometry — it only resolves the given classification into the dof partition (patch_free_dofs / patch_prescribed_dofs). Defaults to no prescribed dofs.
  • field: the field the partition and patch_vertex_dofs resolve against. Defaults to the sdh's only field.

Experimental: the patch item surface may change with the local-BVP work.

source
FerriteOperators.PatchLocalSink — Type
PatchLocalSink(dest)

Patch-local sink: patch i is assembled into dest[i], indexed by patch-local dofs and zeroed by the driver. dest[i] is a matrix for a PatchMatrixKind and a vector for a PatchVectorKind; scatter is by scalar indexing, so a sparse dest[i] GROWS its pattern for entries it does not yet hold.

source
FerriteOperators.PatchMatrixKind — Type
PatchMatrixKind(terms, sink)

Assemble a patch-local MATRIX from a tuple of PatchTerms. Terms reach the element as JacobianRequest{:u} over the element buffer; a term with nothing data runs the element's ordinary Jacobian kernel (including the AD fallback), a term with data goes to assemble_patch_cell!.

source
FerriteOperators.PatchTerm — Type
PatchTerm(restriction, data = nothing)

One additive contribution of a patch request. restriction is WholePatch or CellGroup; data is the element-specific term payload handed to assemble_patch_cell! (nothing selects the element's ordinary cell kernel).

A request carries a tuple of terms. All terms of one request are evaluated in a single pass over the patch's cells and accumulate into the same element buffer in tuple order — the accumulation order is part of the contract. Terms that must fuse at quadrature-point level (rather than at cell level) belong in ONE term whose data carries both sources.

source
FerriteOperators.PatchTripletSink — Type
PatchTripletSink{Tv}(columns)
PatchTripletSink(columns)

Ordered COO sink for vector-valued patch results: patch i emits the triplets (patch_dofs(provider, i)[l], columns[i], v[l]) in ascending l. Duplicate (row, col) entries are SUMMED by sparse(sink, m, n) — patch-additive quantities (a corrector basis assembled from overlapping patches) rely on that.

The emission order is the item order, so a sequential sweep is reproducible bit-for-bit. Callers running their own parallel chunks collect into one sink per chunk and append! them back in chunk order to keep that property. emit_patch_column! is public: a local SOLVE's result is emitted the same way an assembled vector is.

source
FerriteOperators.PatchVectorKind — Type
PatchVectorKind(terms, sink)

Assemble a patch-local VECTOR from a tuple of PatchTerms — the right-hand side of a local BVP. Terms reach the element as ResidualRequest over the element buffer; a term with nothing data runs the element's ordinary residual kernel, a term with data goes to assemble_patch_cell!.

source
FerriteOperators.WholePatch — Type
WholePatch()

Term restriction: integrate over every cell of the patch.

source
FerriteOperators.assemble_patch_cell! — Function
assemble_patch_cell!(req, cache, args, data)

Element kernel for one PatchTerm on one cell: accumulate the term's contribution into req's buffer, exactly as assemble_cell! does. data is the term payload from the request; the nothing payload dispatches to the element's ordinary cell kernel, so unrestricted patch assembly reuses existing elements unchanged.

Term kernels are analytic — there is no AD fallback for a custom payload.

source
FerriteOperators.assemble_patch_matrices! — Function
assemble_patch_matrices!(dest, op, provider::PatchItems, states, p, ctx = nothing)

Assemble the patch-local Jacobian of every patch into dest[i] (a matrix of size patch_ndofs(provider, i) square, zeroed here), reusing the operator's cell kernels; rows/columns follow patch_dofs. Shorthand for assemble_patches! with one whole-patch term and a PatchLocalSink.

Experimental: part of the patch item family.

source
FerriteOperators.assemble_patches! — Function
assemble_patches!(kind, op, provider::PatchItems, states, p, ctx = nothing)

Run one patch sweep of kind (PatchMatrixKind or PatchVectorKind) over every item of provider, reusing the operator's element caches. Each patch is visited once, its cells in ascending order; the kind's sink receives the patch-local result. Sequential CPU only.

Patch sweeps are pure evaluation: condensed element unknowns are gathered but never written back, unlike the global sweeps.

Experimental: part of the patch item family; the local BVP itself (partition, solve, item state) is the caller's — see patch_free_dofs and PatchItemStates.

source
FerriteOperators.augment_prescribed_dofs! — Method
augment_prescribed_dofs!(provider, i, localdofs)

Add localdofs (patch-local) to patch i's prescribed set and recompute the free set. The facet classification is not a closed rule: callers pin extra dofs the local BVP needs to be well posed (e.g. floating components of a perforated patch that no prescribed facet touches). Setup-time mutation — call before any sweep reads the partition.

FerriteOperators.whole_patch_terms — Method
whole_patch_terms(terms::Tuple)

The WholePatch-restricted subtuple of terms, order preserved. Restrictions are tuple type information, so this folds at compile time — elements that fuse several terms per quadrature point use it to select a monomorphic loop for non-group cells instead of threading Union-typed values through the quadrature loop.
