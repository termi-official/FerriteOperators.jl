FerriteOperatorsExampleElements.FerriteOperatorsExampleElements — Module

Example elements for FerriteOperators.

The elements here are minimal, readable implementations of the element contract — one per feature the contract exposes: a bilinear form (SimpleBilinearDiffusionIntegrator, SimpleBilinearMassIntegrator), a linear form (SimpleLinearIntegrator), a nonlinear element with analytic tangent (SimpleHyperelasticityIntegrator) and a condensed element with per-quadrature-point internal state (SimpleCondensedLinearViscoelasticity).

They are meant to be read, copied and used as test fixtures. They are not tuned for production use and carry no stability guarantee beyond the element contract they demonstrate.

FerriteOperatorsExampleElements.MaxwellParameters — Type

Material parameters of the standard linear solid used by SimpleCondensedLinearViscoelasticity: the two spring moduli E₀, E₁, the shear modulus μ, the dashpot viscosity η₁ and Poisson's ratio ν.

FerriteOperatorsExampleElements.SimpleCondensedLinearViscoelasticity — Type
SimpleCondensedLinearViscoelasticity

Linear viscoelasticity (standard linear solid) with the viscous strain εᵛ as a condensed per-quadrature-point internal variable. The element owns the LOCAL stage problem for εᵛ (scaled by ctx.γ̃); the previous state arrives through the uprev slot and the trial state is written back into the element-local u buffer per the condensation contract.

source
FerriteOperatorsExampleElements.SimpleCondensedLinearViscoelasticityCache — Type

The cache associated with SimpleCondensedLinearViscoelasticity. It carries the element-local dof ranges of the displacement and of the condensed viscous strain, and declares has_internal_state.

FerriteOperatorsExampleElements.SimpleHyperelasticityElementCache — Type

The cache associated with SimpleHyperelasticityIntegrator. It serves the residual, the Jacobian and the fused Jacobian-residual analytically, all three from Tensors derivatives of the energy.
