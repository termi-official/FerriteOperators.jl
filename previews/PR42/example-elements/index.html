FerriteOperatorsExampleElements.FerriteOperatorsExampleElements — Module

Example elements for FerriteOperators.

Minimal, readable implementations of the element contract — one per feature it exposes: a bilinear form (SimpleBilinearDiffusionIntegrator, SimpleBilinearMassIntegrator), a linear form (SimpleLinearIntegrator), a nonlinear element with analytic tangent (SimpleHyperelasticityIntegrator), a condensed element with per-quadrature-point internal state (SimpleCondensedLinearViscoelasticity) and one whose local problem is nonlinear and communicates with the outer solver (SimpleCondensedPowerLawRelaxation).

Meant to be read, copied and used as test fixtures: not tuned for production use, and carrying no stability guarantee beyond the contract they demonstrate.

FerriteOperatorsExampleElements.InexactLocalSolveContext — Type
InexactLocalSolveContext(inner, local_tolerance)

Decorates inner with the local residual tolerance the outer solver asks element-local problems to solve to this sweep (the inexact-Newton forcing term, e.g. ηₖ‖F(uₖ)‖), consumed once per trial point at condense_internal! time rather than on every sweep that solves. Elements read it through local_solve_tolerance; framework context handling (evaluation_time, with_time) passes through to inner.

FerriteOperatorsExampleElements.LocalNewtonSettings — Type
LocalNewtonSettings(; max_iterations = 25, tolerance = 1.0e-12)

Static configuration of the element-local Newton solver of SimpleCondensedPowerLawRelaxation: the per-quadrature-point iteration budget, and the tightest absolute local residual tolerance the element ever solves to — a solver may only LOOSEN it, per local_solve_tolerance. Exceeding the budget is reported through CondensationReport.converged, not thrown.

FerriteOperatorsExampleElements.NortonRelaxationParameters — Type

Material parameters of the power-law relaxation model used by SimpleCondensedPowerLawRelaxation: diffusivity κ, exchange modulus α between field and internal state, dashpot viscosity η and Norton exponent n (n = 1 degenerates to a linear dashpot).

Generic over T and promoting so that rebuild_parameters can return a DUAL-valued bag from a seeded θ, as every generic parameter path needs; a monomorphic field type would reject it.

FerriteOperatorsExampleElements.SimpleCondensedLinearViscoelasticity — Type
SimpleCondensedLinearViscoelasticity(material_parameters, qrc, displacement_name, viscosity_name;
                                      corrector = Stored())

Linear viscoelasticity (standard linear solid) with the viscous strain εᵛ as a condensed per-quadrature-point internal variable. The element owns the LOCAL stage problem for εᵛ (scaled by stage_scaling(ctx)), a direct solve per quadrature point in condense_cell! — condense_internal! must run before any evaluation sweep.

corrector elects where the Mandel factorization A of the local operator, the Consistent kernel's input, comes from (CorrectorElection): Stored() retains it per quadrature point, Recompute() re-forms it in the kernel from the same ℂ and γ̃ — a 6×6 matrix per quadrature point against one Mandel assembly per Jacobian sweep. Only the recomputing path reads stage_scaling(args.ctx), so only it requires a context.

FerriteOperatorsExampleElements.SimpleCondensedLinearViscoelasticityCache — Type

FerriteOperatorsExampleElements.SimpleCondensedPowerLawRelaxation — Type
SimpleCondensedPowerLawRelaxation(material_parameters, qrc, field_name, internal_name;
                                   local_solver = LocalNewtonSettings(),
                                   corrector = Stored())

Diffusion of a scalar field u exchanging with a condensed per-quadrature-point internal state q across a power-law (Norton) dashpot:

\[r(u, q) = \int_\Omega \kappa\, \nabla u \cdot \nabla \delta u + \alpha\, (u - q)\, \delta u \; \mathrm{d}\Omega , \qquad \dot q = \frac{\sigma\, |\sigma|^{n-1}}{\eta}, \quad \sigma = \alpha\,(u - q) .\]

The element owns the LOCAL stage problem q = q_prev + γ̃ · q̇(u, q), nonlinear for n ≠ 1, solved per quadrature point by a Newton iteration started at q_prev inside condense_cell! — condense_internal! must run before any evaluation sweep. The Consistent kernels read the implicit-function-theorem slopes dq/du and dq/dθ, so the element is admissible under the internal-state rule.

It talks to the outer solver both ways: inward the requested local tolerance (local_solve_tolerance, clamped from below by the element's own LocalNewtonSettings), outward the CondensationReport.

corrector elects where those slopes come from (CorrectorElection): Stored() keeps them per quadrature point, Recompute() re-derives them from the converged (u, q) in the kernel that needs them. Both produce the same numbers.

FerriteOperatorsExampleElements.SimpleCondensedPowerLawRelaxationCache — Type

The cache associated with SimpleCondensedPowerLawRelaxation. Under a Stored election it holds the per-quadrature-point slopes the Consistent kernels read — correctors (dq/du) and param_correctors (dq/dθ, θ = (α, η, n)) — and nothing in both fields under Recompute, which re-derives them in the kernel. weight, the solver's :u chain-rule scalar of the last condensation, is O(1) per cache and kept under either election: a Stored() slope has it folded in, the recomputing path reads it back. Declares has_internal_state.

FerriteOperators.assemble_cell! — Method
assemble_cell!(req::JacobianRequest{:q}, cache::SimpleCondensedPowerLawRelaxationCache, args) -> K

∂F/∂q, the LOCAL ndofs × nqp block a Schur-complement consumer or a generic corrector combination wants. A pure function of (u, q) — no store needed, and Consistent and FrozenQ coincide because q is the seed itself. K is sized by the caller: q's dofs are internal to the cell, so there is no global scatter target and never a global sweep for this kind.

FerriteOperators.condense_cell! — Method
condense_cell!(cache::SimpleCondensedLinearViscoelasticityCache, args, weights) -> CondensationReport

Solve the local viscous-strain problem at every quadrature point — a direct linear solve, always converged with zero inner iterations — write the trial εᵛ and retain the Mandel factorization A.

FerriteOperators.condense_cell! — Method
condense_cell!(cache::SimpleCondensedPowerLawRelaxationCache, args, weights) -> CondensationReport

Solve the local Norton-dashpot problem at every quadrature point and write the trial q. A Stored election stores the slopes dq/du and dq/dθ alongside; Recompute does not, and the kernels re-derive them from the pair this hook converged.

FerriteOperatorsExampleElements.local_solve_tolerance — Method
local_solve_tolerance(ctx) -> tolerance or `nothing`

The local residual tolerance the outer solver requests for this sweep. nothing, the default for every context type, leaves the element at its own LocalNewtonSettings tolerance — which is also the floor: a tighter request is ignored.
